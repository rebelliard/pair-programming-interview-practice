# Pairing advice and phrases

## Compact working loop

Use **Goal → Options → Choice → Check**:

1. State the smallest useful goal.
2. Name the options that matter.
3. Choose one and say why.
4. Run the focused check.
5. Summarize the result before the next slice.

## Useful phrases

> Can I take a quiet minute to trace the request path, then explain it back?

> My smallest end-to-end slice is X. I expect this check to show Y.

> I see two reasonable choices. I would choose X because Y. Does that match the
> product intent?

> I have been stuck for a couple of minutes. My current theory is X; I would
> inspect Y next. Would you steer me?

> I used the tool to do X. Before I keep this change, I will check Y.

## When time is short

Protect a working, tested vertical slice. State what remains instead of quietly
starting a larger refactor. A small solution that you can explain is better
evidence than an unfinished redesign.
