# Slide-deck guide

Present [`deck.md`](deck.md) with a Markdown slide viewer such as Marp. Keep
the later release slides hidden until their scheduled gate.

| Slides                      | When to show                        |
| --------------------------- | ----------------------------------- |
| Title through “Walkthrough” | Before Core                         |
| “Core release”              | Minute 12                           |
| “Extension release”         | After Core is substantially working |
| “Stretch release”           | After Extension is green            |
| Handoff and debrief         | Minute 42                           |

The deck is a shared conversation aid. Keep the facilitator playbook, private
acceptance tests, and reference patch on a private screen.
