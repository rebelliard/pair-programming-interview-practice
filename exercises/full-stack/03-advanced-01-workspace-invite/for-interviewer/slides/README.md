# 🖥️ Slide-deck guide

Use [`deck.md`](deck.md) to stage the workspace invitation exercise. Keep this
folder private from the candidate.

## 🗺️ Reveal plan

| Slide                               | When to show it                        |
| ----------------------------------- | -------------------------------------- |
| Title through “Explore the starter” | Before and at minute 2                 |
| “Product request: invite a member”  | Minute 10                              |
| “Brief coaching pause”              | Minute 28                              |
| “Product request: seat limit”       | Minute 30 when core is working         |
| “Optional stretch: accept”          | Before minute 36 when extension passes |
| “Handoff”                           | Minute 39                              |
| “Debrief”                           | Minute 42                              |

## 🎬 Before presenting

1. Open the deck in presenter mode.
2. Confirm that speaker comments are not visible on the shared screen.
3. Keep the facilitator playbook open on a private screen.
4. Reveal each product slide only at its agenda point.
