# Full-stack

Level is the expected comfort for an intermediate product engineer in the
session time shown. It ranks this series, not the industry in general. Expert
here means the process is the stretch, not that the code is undoable.

| Order                                                                                 | Format            | Level           | Primary concepts                                                                                   |
